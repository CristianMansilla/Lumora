# LUMORA

LUMORA es una propuesta modular del equipo INGESIST para coordinar información y recursos en la post-emergencia. Integra cuatro subsistemas:

- **HUGIN:** drones de reconocimiento y relevamiento del territorio.
- **MUNIN:** red descentralizada de comunicaciones y transporte de reportes.
- **ISCAT:** cápsulas con sensores acústicos y ambientales para registrar posibles indicios que requieren verificación.
- **Conciencia Colectiva:** integración de reportes y recomendaciones explicables bajo supervisión humana.

El sitio presenta la propuesta para el Rally Latinoamericano de Innovación 2026, desafío 09. Incluye una ciudad 3D y una simulación conceptual de HUGIN, MUNIN, ISCAT y Conciencia Colectiva. Usa datos ficticios y reglas deterministas; no representa una implementación física validada ni IA entrenada.

## Ejecutar

```bash
npm install
npm run dev
```

Abrí la dirección local que muestra Vite. Para generar la versión de producción:

```bash
npm run build
npm run preview
```

Para revisar el código:

```bash
npm run lint
```
